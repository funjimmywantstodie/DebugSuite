# DebugSuite

A Roblox/Luau debugging workspace built on **SimpleUI**, a reusable UI library
for executor runtimes. The Functions tab searches by name and constants: press
Enter in either search textbox or click **Search**. Clicking away updates the
filter without searching. The GC tab has refresh placeholders; the app also
checks the executor APIs it needs.

The Function and Table Inspect windows expand their scrolling panels when
resized. Short windows keep a minimum panel height and scroll the outer content.

## Features

- Draggable, resizable windows with focus ordering and additional floating windows.
- Tabs, sections, rows, scrolling panels, and adjustable split panes.
- Buttons, textboxes, toggles, dropdowns, and action menus.
- Lists with columns, filtering, sorting, and selection; expandable trees with lazy loading.
- Read-only or editable text viewers with Lua/Luau syntax highlighting and raw text getters.
- Consoles with message levels, entry limits, pause, and automatic scrolling.
- Notifications, a built-in log console, keyboard shortcuts, and automatic cleanup.

See [UI docs](UIDOCS.md) for examples, options, and methods.

## Build and run

Building requires Python 3 and `darklua` (the version is pinned in
[rokit.toml](rokit.toml)). Running requires a Roblox executor with the necessary
APIs, including `getgenv`, `cloneref`, and access to `CoreGui`.

1. Copy [.env.example](.env.example) to `.env` in the repository root and set
   `DEBUGSUITE_WORKSPACE` to your executor's workspace folder. Leave it empty
   to skip copying. The local `.env` file is ignored by Git.
2. Run `python3 tools/build.py` from the repository root.
3. Execute [dist/DebugSuite.lua](dist/DebugSuite.lua), or save
   [tools/Bootstrap.lua](tools/Bootstrap.lua) in your executor to load the
   workspace copy on each run. The bootstrap requires `loadfile`.

On Windows, use `py -3` instead of `python3` if needed. Rebuild after editing
source files.

For example, your `.env` on macOS can contain:

```dotenv
DEBUGSUITE_WORKSPACE="/Users/max/Documents/Macsploit Workspace"
```

On Windows, use a path such as `DEBUGSUITE_WORKSPACE="C:\path\to\workspace"`.
An existing `DEBUGSUITE_WORKSPACE` shell environment variable overrides `.env`.
If you previously exported it in zsh, run `unset DEBUGSUITE_WORKSPACE` and remove
that export from `~/.zshrc` to use `.env` instead.
