## Options (`opts`)

`opts` is just a table: `section:NewButton({ text = "Run" }, callback)`.
`opts?` means the table is optional; omit it or use `{}` for defaults.
In option tables, `?` means optional. Keys are case-sensitive (`size`, not `Size`).
Heights, widths, gaps, and padding are in pixels. Use `UDim2` for size/position,
`Vector2` for size constraints, and a number for split-pane `minSize`.

## Basic pattern

```lua
-- GENERATED BY AI — This example was generated by AI.
-- In a file inside src/:
local Window = require("./ui/Window")
local window = Window.new({ captureLogs = false })
local tab = window:NewTab("Tools")
local section = tab:NewSection("Actions", "left")
section:NewButton({ text = "Hello" }, function()
    window:Notify({ text = "Hello!", messageType = "success" })
end)
window:SelectTab(tab)
window:Show()
```

`Window.new` replaces the previous main UI. Use `window:NewWindow` for extra
windows belonging to that UI. Use sections or panels to arrange multiple controls.
Every example runs independently; rerunning cleans up the previous UI.
