## Build and run

From the repository root, bundle the chosen example:

```sh
# GENERATED BY AI — This command example was generated by AI.
darklua process docs/ui/examples/basic-tabs.lua /tmp/simpleui-basic.lua
```

Execute the generated file's contents in your executor. Change the input filename
for the other examples. Use a writable output path on your machine (for example
`dist/Example.lua` on Windows). Python and the app build script are not needed.
The library requires Roblox plus `getgenv`, `cloneref`, and access to `CoreGui`.
The unbundled files cannot run directly in an executor.

When copying an example into `src/`, change its require to `require("./ui/Window")`.
When adding an inspector to your app, reuse its existing `window` and call
`window:NewWindow`; remove the example's `Window.new` setup.

## Common patterns

| Task | Use |
| --- | --- |
| Arrange controls | A section, or a panel inside a floating window/split-pane half. |
| Fill available space | `size = UDim2.fromScale(1, 1)` on the outer component. |
| Open a reusable tool window | Create it with `visible = false`, `closeBehavior = "hide"`; call `Show` from a button. |
| Show flat records | `NewList`, `SetRecords`, and `OnSelected`. |
| Show nested tables | `NewTree` and lazy `loadChildren`; preserve values in `data`. |
| Show/edit source text | `NewTextViewer`; `GetText` returns raw text even with highlighting. |
| Subscribe to changes | `OnChanged`, `OnSubmitted`, or `OnSelected`; returned connections can be disconnected. |
| Attach your own Roblox events | `component.scope:Connect(signal, callback)` for automatic cleanup. |
| Release a tool | `Destroy` removes instances/events; `Hide` preserves them. |

The table inspector reads ordinary Luau tables. It shows values with `tostring`,
loads children on expansion, marks cycles, and limits displayed depth to 8.
It does not scan executor objects. Refresh rebuilds the tree and clears selection.
Mocks can check logic and cleanup; rendering, text selection, and dragging still
need a real Roblox runtime check.
