# Windows and tabs

[UI docs](README.md) · [Examples](examples/README.md)

### Main window

Syntax: `Window.new(opts: table?) → Window`

| Option | Type | Description |
| --- | --- | --- |
| `size` | `UDim2?` | Initial size; default `UDim2.fromScale(0.5, 0.5)`. |
| `minSize` | `Vector2?` | Minimum size; default `Vector2.new(400, 260)`, clamped to at least that size. |
| `captureLogs` | `boolean?` | Capture LogService output; default `true`. |

Starts visible and centered. Creating a main window destroys the previous
SimpleUI window and cleans up its UI.

| Main window method | Purpose |
| --- | --- |
| `NewTab(name, opts?)`, `SelectTab(tab)` | Create a tab, then select it explicitly. |
| `Show()`, `Hide()`, `Toggle()`, `SetVisible(bool)` | Control the entire UI. |
| `NewWindow(opts?)` | Create an owned floating window. |
| `OpenConsole()` | Show the built-in console and return its console component. |
| `Log(text, level?)` | Add a console entry; defaults to `"info"`. |
| `Notify(opts)` | Show a notification and log its full message. |
| `BindShortcut(key, callback, opts?)` | Bind an `Enum.KeyCode`; options are `ctrl` and `shift`. |
| `Clear()`, `Destroy()` | Remove tabs, or destroy the entire UI. |

Shortcut options for `window:BindShortcut(key, callback, opts?)`:

| Option | Type | Description |
| --- | --- | --- |
| `ctrl` | `boolean?` | Require Ctrl; default `false`. |
| `shift` | `boolean?` | Require Shift; default `false`. |

Returns an `RBXScriptConnection`. Shortcuts require the exact Ctrl/Shift combination.
They are ignored while a textbox is focused, input is processed, or the UI is hidden.

### Shared content API

Tabs and floating windows expose the same `NewSection(name, side?)` and component
methods (`NewButton`, `NewTextbox`, `NewLabel`, `NewList`, `NewPanel`, and the other
[container methods](layouts.md)). A content builder can accept either host:

```lua
-- GENERATED BY AI — This example was generated by AI.
local function buildMetadata(host)
    local section = host:NewSection("Function Metadata", "full")
    section:NewLabel({ text = "Select a function to inspect" })
    return section
end

local tab = window:NewTab("Inspect")
local inspector = window:NewWindow({ title = "Inspect" })
buildMetadata(tab)
buildMetadata(inspector)
window:SelectTab(tab)
```

`NewSection` takes a name string and an optional side, not an options table.
Sides are `"left"` (default), `"right"`, `"top"`, `"bottom"`, or `"full"`.
With `layout = "sections"` (the default for both hosts), sections grow to fit
their controls and the host scrolls vertically. Top and bottom span both columns;
`"full"` uses the bottom area. Bottom sections sit below the taller column.
Components added directly to the host use its bottom area.

Both hosts support `layout = "free"` for manually positioned content. There is
no automatic section placement or canvas sizing in that mode; all section sides
use the same content frame. Set positions and sizes yourself, or use a full-size
panel or split pane. A main window creates hosts through `NewTab` and `NewWindow`;
it does not expose their content methods directly.

`Clear()` destroys a host's child components, including sections, and keeps the
layout reusable. `Destroy()` also releases its layout connections and instances.

### Tabs

Syntax: `window:NewTab(name: string, opts: table?) → Tab`

| Option | Type | Description |
| --- | --- | --- |
| `layout` | `string?` | `"sections"` (default) or `"free"` for manual placement. |

Use `NewTab(name, { layout = "free" })` for manual layouts. Destroying the
selected tab selects the first remaining tab.

### Floating windows

Syntax: `window:NewWindow(opts: table?) → FloatingWindow`

| Option | Type | Description |
| --- | --- | --- |
| `name` | `string?` | Instance name; default `"Root"`. |
| `title` | `string?` | Title-bar text; default `""`. |
| `size` | `UDim2?` | Initial size; default `UDim2.fromScale(0.5, 0.5)`. |
| `position` | `UDim2?` | Center position; default `UDim2.fromScale(0.5, 0.5)`. |
| `minSize` | `Vector2?` | Minimum size; default `Vector2.new(400, 260)`. |
| `visible` | `boolean?` | Start visible; default `true`. |
| `closeBehavior` | `string?` | `"destroy"` (default) or `"hide"` to preserve contents. |
| `backgroundColor` | `Color3?` | Body background; default `Colors.tabContainer`, matching the main window's tab body. |
| `layout` | `string?` | `"sections"` (default) or `"free"`, matching tabs. |

Floating windows now default to the same section layout as tabs. For existing
windows that put a full-size viewer, console, panel, or split pane directly in
the body, set `layout = "free"` to preserve that manual layout.

Example—an inspector alongside the main UI:

```lua
-- GENERATED BY AI — This example was generated by AI.
local inspector = window:NewWindow({
    title = "Function Inspect",
    layout = "free",
    size = UDim2.fromOffset(400, 300),
    position = UDim2.fromScale(0.5, 0.5),
    closeBehavior = "hide",
})
inspector:NewTextViewer({ text = "Select a function", size = UDim2.fromScale(1, 1) })
```

Methods:
`Show()`, `Hide()`, `Toggle()`, `SetVisible(bool)`, `Focus()`, and
`AddTopbarButton(name, text, callback, width?)` (width defaults to 60 pixels;
returns a `TextButton`), plus the shared content and cleanup methods above.

Drag title bars and resize from bottom-right corners. Clicking a window or its
controls brings it forward. Notifications stay above windows; only the
frontmost window under the pointer can start a drag or resize.
